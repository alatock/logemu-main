# loGemu emulator v1.0
КАК ЗАПУСТИТЬ ФАЙЛ:

1. Скачайте проект, распакуйте и скопируйте свой код сюда: ваша папка с проектом/rmdc/main.txt

2. запустите файл loGemu_main.py, загрузите необходимые библиотеки.

3. Вуаля! код работает. чтобы выводить какую-либо информацию из регистров, используйте в вашем коде: out. "r" r(номер) P5.

Таким образом содержимое из регистра будет выведено в терминал. Удач!
